# LabSpotter app (private build branch, DEVELOPMENT) - NOT a finished detector

Flow: 4 s clip (16 frames, 4 fps) -> frozen V-JEPA2 SSv2 checkpoint (facebook/vjepa2-vitl-fpc16-256-ssv2, revision 4aa02df8): encoder last-hidden-state mean h (1024-d) plus the checkpoint's own SSv2 classifier logits lg (174-d), concatenated to 1198-d [h, lg] -> our own trained head (heads/frozen384.pkl, StandardScaler + LogisticRegression; the SSv2 labels themselves are not used as predictions) -> Facts -> Meta agent (OFFLINE here) -> code gate -> pending_review alert. The model output is a claimed presence only. The gate decides step status; every step stays UNVERIFIED, approval stays NONE RECORDED, and the VALIDATED registry is empty.

Selected head: `heads/frozen384.pkl` (sha256 c5af2cb494eeee2880ec8d7103df10f522dfd2be5de68eb42f8548bc4c733c64), chosen by `heads/active.json`. Measured: balanced accuracy 0.512 on the 229 official validation clips (5 sources), 8 classes. The 75% bar is NOT met, and that validation set is spent (development data now). Balanced accuracy is a different metric from raw accuracy; do not compare them directly. `heads/candidate_c003_1427.pkl` is a candidate and is NOT selected (0.528 balanced on the same 229 clips, a small difference not tested for significance).

## Run (one entrypoint)
- Backend + GUI: `python3 server.py` (127.0.0.1:8765; session token printed once, type it into Run > token). Real analysis needs torch, transformers, pillow and ffmpeg, about 3 GB RAM; the first encoder call downloads about 1.5 GB of weights; CPU is about 20 s to 1 min per clip.
- Local run helper (this computer only, not hosting): `bash ./run_local.sh [--check | --check-wheels] [--port N]` checks Python 3.10+, ffmpeg and the port, creates `.venv`, installs torch==2.11.0+cpu and torchvision==0.26.0+cpu (the video processor needs it) then requirements.txt with transformers==5.16.1 and Pillow==13.0.0 (12.3.0 on Python 3.10, which has no 13.0.0 wheels), and starts server.py on 127.0.0.1. The token comes from LABSPOTTER_TOKEN or the file `.run/token` (created with mode 0600, never printed). `--check` is a dry run that installs and creates nothing; `--check-wheels` asks the package index whether every pinned package has a wheel for that Python (needs network, installs nothing). These pins are versions known to work here, not a lockfile. On 2026-11-02 the install step ran for real once on one Linux box with Python 3.10.12 (fresh venv, all installs succeeded); starting the server through run_local.sh has not been tested, and other Python versions only passed `--check-wheels`.
- Command line: `python3 chain/action_clip.py <tag> clip1.mp4 [clip2.mp4 ...]`.
- Head config: `heads/active.json`; override with LABSPOTTER_HEAD_CONFIG. If the config or the head file is missing the program exits with a clear message and never guesses a head.
- Meta agent: offline. `--live` is refused unless LABSPOTTER_LIVE_CLEARED=1 and MODEL_API_KEY are set; this branch is not cleared for live calls.
